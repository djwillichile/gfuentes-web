# gfuentes.cl — versión nueva

Sitio personal de Guillermo S. Fuentes-Jaque. HTML, CSS y un poco de JavaScript, sin dependencias ni paso de compilación.

Mientras se publica en paralelo en `nueva.gfuentes.cl`, la página lleva `noindex` y un canonical a `https://gfuentes.cl/`.

## Lanzar en gfuentes.cl

1. Quitar `<meta name="robots" content="noindex, follow">` de `index.html`.
2. Cambiar `CNAME` a `gfuentes.cl`.
3. Apuntar el dominio principal a este repositorio en GitHub Pages.

## Estructura

| Ruta | Qué contiene |
| --- | --- |
| `index.html` | Todo el contenido, en el HTML |
| `styles.css` | Estilos: verde botella y dorado, Unbounded y Onest |
| `main.js` | Portada, recorrido de latitudes y proyectos fijados al scroll |
| `assets/img`, `assets/video` | Imágenes y video satelitales (NASA, dominio público) y capturas de proyectos propios |
| `assets/fonts` | Unbounded y Onest servidas desde el sitio |
| `docs/` | Currículum en PDF |

## Créditos de imágenes

Imágenes y video satelitales de la NASA (MODIS, Landsat, HLS y fotografías de la Estación Espacial Internacional), dominio público, vía Wikimedia Commons. Las capturas de proyectos son obra propia.
